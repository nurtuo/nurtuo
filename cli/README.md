# nurtuoctl (Apache-2.0)

Developer and CI tool: `validate`, `fmt`, `diff`, `init`, `login`, `component`, `flow push|pull`,
`deploy`, `runtime list`, `completion`. Uses the same flow-validate library as the canvas and the MCP
server, and `@nurtuo/client` for the control-plane API.

See [docs/cli.md](../docs/cli.md) for the full reference, exit codes and CI usage.
